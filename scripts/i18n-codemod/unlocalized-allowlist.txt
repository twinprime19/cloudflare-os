# Strings the unlocalized-string detector should stop reporting, and the files it should skip
# entirely. Read by `scripts/i18n-codemod/detect.ts`; the same list suppresses the codemod, so an
# entry here means "never wrap this", not "wrap it later".
#
# One entry per line. `#` starts a comment, blank lines are ignored. Paths are relative to the
# repository root and use `/` on every platform.
#
#   packages/workshop-frontend/src/some/directory/   trailing slash: every file under it
#   packages/workshop-frontend/src/SomeFile.tsx      one file
#   packages/workshop-frontend/src/SomeFile.tsx|Exact text   one string in one file
#   *|Exact text                                     one string, any file
#
# The text is matched after collapsing runs of whitespace, so wrap it on one line here however it
# is wrapped in the source.
#
# Add an entry only for text a user genuinely never reads, or reads as a literal token that must
# not change between languages -- a protocol name, a header, a code sample. Copy that is merely
# awkward to wrap belongs in the residue list, not here.
#
# Everything below covers `.ts` files. A `.ts` file has no JSX, so the detector judges its string
# and template literals directly, and the positions it can rule out from syntax alone -- log
# arguments, module specifiers, type literals, `.includes()` needles, `className` assignments -- are
# rules in `detect.ts` rather than entries here. What is left needs knowledge of the program that
# a parser does not have, so it is written down, one line at a time, with the reason.
